[1. 상단 레이아웃 및 테마 디자인 검증]
  - 상단 헤더: 네이비 그라데이션 (#0F2027 ~ #2C5364) 타이틀 바 렌더링 정상
  - 색상 팔레트: 임원 보고용 네이비, 민트(#00C9A7), 화이트, 슬레이트 톤 적용 완료
  - 반응형 디자인: 데스크톱 및 모바일 화면 자동 리사이징 확인

[2. 4대 핵심 KPI 지표 카드 검증]
  - 전체 문서 수: 240건 (영수증 120건 / 설문지 120건) 정상 집계
  - OCR 인식 성공률: 100.0% (OpenCV 전처리 보정 반영)
  - 결측치 보완 건수: 25건 (보완율 10.4%) 정상 표시
  - 평균 OCR 신뢰도: 97.0% (High-Confidence Index)

[3. 시각화 차트 렌더링 검증]
  - 영수증 카테고리 도넛 차트: 인쇄제본, 사무용품, 클라우드 등 비중 정상 표시, 툴팁 금액 서식 적용
  - 설문 부서별 막대 차트: 기획팀, 데이터팀, 교육팀, 영업팀, 총무팀 평점(1~5점) 정상 렌더링
  - 품질 환경별 신뢰도 차트: 일반 고해상도, 노이즈, 저해상도 환경별 비교 막대 정상 출력
  - 차트 깨짐 및 오버플로우: 이상 없음 (0건)

[4. 데이터 테이블 및 검색/필터 검증]
  - 탭 1 (확인필요/보완 목록): 25건 필터링 및 보완사유 라벨 정상 렌더링
  - 탭 2 (전체 데이터셋): 240건 전체 레코드 검색 및 정렬 정상 작동
  - 실시간 검색 바: 키워드(ID, 부서, 상호명, 메모) 입력 시 즉시 필터링 동작
  - 사이드바 필터: 문서유형(전체/영수증/설문지), 소속부서, 이미지 상태 필터 연동 정상

[5. 원본 vs 전처리 이미지 비교 뷰어 모달 검증]
  - 원본 이미지 로딩: data/input_images/... 정상 표시
  - 전처리 이미지 로딩: data/ocr/preprocessed_images/... 정상 표시
  - 1:1 비교 뷰어: 원본과 이진화/노이즈제거 이미지 좌우 비교 정상 동작
  - 메타데이터 JSON 뷰어: 필드별 추출값 정상 포맷팅
